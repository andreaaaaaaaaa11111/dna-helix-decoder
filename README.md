# DNA → Code: The Helix Decoder

An interactive canvas visualization where a **DNA double helix** scrolls upward and its rungs morph into **syntax-highlighted lines of code** — biology meets programming in a neon-lit animation.

## Features

- **800×800 canvas** with a 3D double helix rendered in real time
- **Neon glow effects** on both strands (cyan and pink) with particle bursts
- **Decode threshold line** — when a rung crosses it, a new code line appears
- **Side panel** with Rust-style syntax-highlighted code that fades in/out
- **Interactive controls**: play/pause, speed adjustment, glow toggle
- **Responsive layout** that adapts to smaller screens
- **Zero dependencies** — pure HTML, CSS, and vanilla JavaScript
